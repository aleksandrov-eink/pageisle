浏览器一键刷机（USB 有线）

用 电脑版 Chrome / Edge，数据线连接设备即可。无需安装驱动工具，不占用本地文件。

内测提示：当前内测包为 1.23.0（2026-11-18 构建）。本版只改一件事：按真机补充的时序证据，把灰影从「擦白不足」改判为擦白过饱和后断电弛豫——灰影是刷新完成后 0.2–0.5 s 才浮出，且刚刷新的头几页干净、翻若干页后才出现。机理：波形表里纸面 (to=15,from=15) 永远 0 拍（trim 与 TEXTTURN 装配都屏蔽等值对），而「上一页有墨 → 这一页白」(to=15,from<15) 吃基表 18/19 拍 + 分级白尾 4/3 = 22 拍；本工程每拍被 EPD_MIN_PHASE_US 垫到 12 ms（Pico 约 7 ms），同一张表的实际电荷约 1.7 倍。修法（C 方案）：白尾之后再补 2 拍动作 1（压黑），只对旧墨 from=0..14 生效、纸面 from=15 仍不驱动；表 43 相 = 34 驱动 + 4 变白 + 2 反向 + 3 保持，8 带 = 50 拍 × 12 ms ≈ 600 ms（比 1.22.1 慢 24 ms）。阅读水波纹与设置页整页翻页同一套。开关：READER_WATER_WHITE_BACK / DISPLAY_SETTINGS_FLIP_WHITE_BACK（0..4），置 0 回到 1.22.1 的 41 相/48 拍/576 ms。未改：全刷路线（周期 48 相 GC16、from_white、反色真 GC16 节奏、清理页计数）、地面白推（DISPLAY_GROUND_SETTLE_EVERY=4）、抗锯齿默认档、分区表、NVS 布局。仍未真机验证：如果 2 拍反向仍不够，下一版按 1 拍步进加到 3（上限 4）；若出现「常驻灰雾」说明过冲，回退到 _BACK=0；再不行改做 D 方案（pclk 20→24 MHz + 相地板 12→10 ms）。升级前请保留 1.22.1 的安装包。

⚠ 刷机确认框里不要勾选 “Erase device” 点刷机后会出现一个英文确认框（Erase device）：保持不勾选，直接点 Next。 勾选它会整片擦除 Flash——设置、阅读记录、阅读统计全部清零（这一版早期页面就踩过这个坑）。
当前浏览器不支持 Web Serial，请改用电脑版 Chrome 或 Edge（89 及以上）。 页面必须通过 HTTPS 或 localhost 打开才能刷机。

刷入后设备会自动重启。若没有自动重启，长按电源键一次即可。请先关闭占用该串口的程序（如 idf.py monitor、串口助手）。

  • 电脑版 Chrome / Edge 89+（不支持 Firefox / Safari / 手机浏览器）
  • 一根能传数据的 USB 线（只供电的线不行）
  • 页面地址是 HTTPS 或 localhost（GitHub Pages 默认满足）
  • 设备：Metalio 4.7 V1.5 · ESP32-S31 · 16 MB flash

按上一条操作（不勾 Erase device）时，刷机只写引导程序、分区表与应用镜像， 设置与阅读记录保留；TF 卡上的书、划线、字体、壁纸也不受影响。

日常升级其实更推荐下面的 TF 卡本地升级：完全不擦除，风险最低。

三步刷完

  1. 连接设备：用能传数据的 USB 线接到电脑，设备保持开机即可（不用按 BOOT）。
  2. 点按钮选串口：选设备对应的那一项（常见名字带 USB JTAG 或 USB Serial）； 之后出现的 Erase device 确认框里不要勾选，直接点 Next。
  3. 等进度走完：写入约 4.9 MB；完成后设备重启，进入锁屏界面。之后可在「设置 → 升级和恢复 → 更新说明」里看到本版条目。

异常恢复模式不再锁死字体

  • 本版允许在保护模式下手动选择系统/阅读字体（仅本次开机生效），加载失败仍回退内建并给提示。
  • 保护模式原因可在串口日志 / 设置诊断中看到，便于反馈；坏字体导致的崩溃保护仍然保留。

常见问题

点按钮没有反应 / 提示不支持

Web Serial 只在电脑版 Chrome、Edge（89+）以及 localhost / HTTPS 页面可用；Firefox、Safari、微信内置浏览器、手机浏览器都不支持。请把页面放在 https 地址（例如 GitHub Pages）或本机 python -m http.server 的 localhost 上打开。

串口列表里找不到设备

先在系统设备管理器里确认能看到 USB JTAG/serial debug unit（或 COM 口）；换一根能传数据的 USB 线；确认设备已开机。Windows 上个别机器需要允许浏览器访问串口设备。

刷机会不会清空我的书和设置？

按正常流程不会。刷写只覆盖引导程序、分区表、应用镜像和 OTA 元数据；书架文件在 TF 卡上，设置与阅读记录在 NVS 数据分区，都不会被动到。唯一会清空的情况是在 Erase device 确认框里勾选了擦除——那会整片擦掉 Flash。

已经不小心勾了 Erase device，记录丢了怎么办？

能恢复的：如果你之前在 设置 → 升级和恢复 → 保存与恢复 里保存过配置到 TF 卡（设置备份文件在 TF 卡根目录），刷完后进同一个页面点「从 TF 卡恢复配置」，设置与阅读记录会回来。
本来就没丢的：TF 卡上的书、划线（.readpico）、字体、壁纸都还在，重新选一下字体/壁纸就能恢复外观。
找不回的：没有备份时，NVS 里的阅读进度、阅读时长统计、锁屏密码、Wi-Fi 密码、手势与按键映射会被清零，只能重设；另外内置存储 /flash/books 里的书也会随内部 FAT 分区一起被擦掉（TF 卡上的书不受影响）。

提示串口被占用 / 打不开端口

先关掉可能占用同一个串口的程序：idf.py monitor、串口助手、Arduino IDE 串口监视器、厂商刷机工具等，等几秒再点刷机。同一个浏览器标签页里重复刷机时，先让上一次连接断开（拔插一次数据线也可以）。

Windows 上需要装驱动吗？

Metalio S31（ESP32-S31）走 USB 串口（USB-Serial/JTAG），Windows 10/11 会自动装好 usbser，一般不需要额外驱动。如果设备管理器里是黄色感叹号，重新插拔一次或换一个 USB 口（不要用只供电的集线器）。

怎么确认刷进去了、是这一版？

刷完开机后：设置 → 升级和恢复 → 顶部「当前版本」应显示 1.23.0；再对照本页的 sha256 与 TF 卡镜像校验值。Markdown 书可以直接用文件管理打开验证。

刷到一半失败 / 断线了怎么办

设备此时停在引导模式，重新连接再刷一次即可；重复刷同一份固件没有副作用。若设备反复重启，用 TF 卡升级方式兜底。

怎么回退到上一版？

和刷机一样：把上一版的 .bin 放 TF 卡根目录用本地升级，或用本页的刷机按钮刷入上一版镜像。分区布局没有变，回退不需要改引导程序。要回到官方原版，下载本页“固件信息”里的 official-rc109-original.bin。

Markdown 里的图片为什么不显示？

这一版 Markdown 只排版文字与结构，图片引用会显示成 [图] alt 占位；Obsidian 插件附带的 attachments/ 目录也不会被下载。图文混排仍在 EPUB 阅读里完整支持。

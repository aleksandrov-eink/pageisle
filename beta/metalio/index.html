浏览器一键升级（推荐，操作流程与 Pico 相同）

电脑 Chrome/Edge + USB 数据线。点下面的按钮 → 选择设备 → 确认 → 自动刷入；只写应用分区和 OTA 选择区，不擦除书籍、设置和存储卡。刷入前请确认电量充足。

需要桌面版 Chrome/Edge（Web Serial）；若连接失败，按提示让设备进入下载模式， 或用下方 TF 卡方式。

TF 卡本地升级（备用）

刷入步骤

  1. 下载上面的 Metalio-S31-update.bin（不要改名、不要解压）；
  2. 复制到 TF 卡根目录（与书籍同一张卡即可）；
  3. 把卡插回设备，进入 设置 → 升级和恢复 → 本地升级（或按屏幕提示），确认后等待完成；
  4. 升级完成后设备重启，版本仍为官方 0.3.3-rc109；官方在线 OTA 检查也保持可用。

⚠️ 本镜像是 app-only 更新包，只写应用分区；刷入前确保电量充足，升级过程中不要断电/拔卡。

回退 / 重刷

保留这个 Metalio-S31-update.bin，任何时候都可以用同样的 TF 卡步骤重刷回官方 rc109； 也可以在设备「升级和恢复」里检查官方在线 OTA。

不要把 Pico 的 Pico-update.bin 刷到 Metalio 上（两台设备硬件/引导不同，会无法启动）； 切换设备时请回到内测通道选择对应型号。

版本说明

  • 本版功能与官方 0.3.3-rc109 完全一致，不含页屿自定义改动；目的是先验证刷机链路，做到"刷了能回"。
  • 没有 Metalio 真机可测，本包为官方原版镜像，风险最低；自定义功能版会在后续内测中提供，并保留官方包用于回退。
  • 在线 OTA：本包保留官方更新源，可正常检查官方新版本；页屿自定义版的在线更新源会在功能版中单独配置。
  • 遇到无法启动：优先用本页的官方包重刷；仍不行则需要 USB 恢复（官方工具）。
